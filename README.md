# icsi418y-PA2-Login-And-Signup
This project was made to test integration between MongoDB and react.js (essentially making a front-end to back-end pipeline). 
In this, you will find a working sign-in section along with a log in section, which catches any mishaps like typing a duplicate username in or having the incorrect password when logging in.

icsi418y-PA3-Projects:

This addon extends the usability of this website, allowing for the creation of projects. This further builds on the knowledge gained on front-backend development using MongoDB and jsx.
You will now find a projects tab when signing in, where you can create projects and establish leads, invite members from the database of MongoDB, and remove them. This utilizes mapping and filtering in order to access retrieved data from the backend server and place them in their desired positions.
